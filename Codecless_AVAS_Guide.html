System Overview

System Overview

A dsPIC33AK512MPS512 samples line-in audio with its own ADC, outputs audio as 192 kHz PWM, synthesises AVAS engine sound and drives an OSP LED strip, all controlled over LIN from the SAMA7D65 HMI. No external audio codec is used.

OSP frame start is atomic

osp.c disables interrupts for about 2 µs around the DMA software trigger and DISSDO = 0. If the PWM3 or ADC ISR hits in that gap, the first Manchester bytes leave with SDO disabled and the LEDs drop the frame (CRC error).

Why Modbus is not polled

nmbs_server_poll() blocks up to 10 ms waiting for a byte. That made the 1 ms tasks run every ~10 ms (slow blip, late LIN response), so the AVAS loop calls only RefEngine_Fill(), LIN_Slave_Process() and OSP_UpdateEffects(). RefEngine_Fill() is called three times per pass to keep the FIFO full.

PWM update order

AudioISR_Process() calls SetPWMDuty() with the previous sample first, then AudioTasks(). This keeps the time between UPDREQ and the PWM SOC window short; the cost is one sample of latency.

Why a FIFO

One engine_process() block takes longer than one 20.8 µs sample interrupt. The main loop is the only producer and the ISR the only consumer, so fifo_wr / fifo_rd need no lock. 21 ms covers the longest stall seen: printf at 115 200 baud costs ~87 µs per character.

Figure 5-2: RPM after LIN 0x13 from 1500 RPM, computed from blip_update()

Blip rules

Ignored while AVAS is off. A new blip restarts from the current RPM, so re-triggering mid-blip is smooth. The decay returns to the live target, so RPM changes during decay are followed. AVAS_IsBlipRising() (attack + hold) drives the white flash of the tachometer when it is enabled.

Break handling

A byte 0x00 with the framing error flag always restarts a frame, even in the middle of one. Every valid frame calls AVAS_LinAlive(); frames with another ID are logged and ignored.

F1MediumIndicatorOSP_DrawIndicatorWave() splits at a fixed LED 21. With fewer than 22 LEDs, right_count = num_leds - 21 wraps (uint8_t), the left wave draws nothing, and the right wave writes LED addresses that do not exist.Use half = min(21, num_leds / 2) or skip the left half when num_leds ≤ 21.
